# company-site

スカイライン・テクノロジーズの企業サイトです。

## 構成

- `index.html` : トップページ(1ファイル完結の静的サイト)

### ページ内容

- ヒーローセクション
- 提供サービス
- 強み(技術力と伴走力)
- 開発実績(一部)
- お客様の声
- お問い合わせ

## ローカルでの確認方法

ビルド不要です。`index.html` をブラウザで開くだけで表示できます。

```sh
open index.html
```

簡易サーバーで確認する場合:

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## ブランチ運用

- `main` : 公開用の安定ブランチ
- `feature/*` : 機能追加・修正用のブランチ
